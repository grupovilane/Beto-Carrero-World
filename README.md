# GS Infinity Travel — Caravana Beto Carrero World 2026

Landing page interativa (React + Vite + Tailwind CSS + Framer Motion) que promove a Caravana Santa Catarina / Beto Carrero World da GS Infinity Travel.

## Rodar localmente

```bash
npm install
cp .env.example .env
npm run dev
```

As variáveis em `.env` são chaves públicas (publishable) do backend Lovable Cloud.
